# Форма регистрации — учебный проект для семинара

Рабочая форма регистрации (телефон + пароль + подтверждение пароля) без сборки, чистый HTML/CSS/JS. Открывается прямо в браузере файлом `index.html`, никакой установки не требуется.

## Как использовать на занятии

1. Залейте этот проект в `main` — это ЭТАЛОННАЯ рабочая версия без багов.
2. Создайте 4 ветки от `main`, в каждой внесите один точечный баг (см. ниже) — это будут стартовые ветки для команд.
3. На занятии каждая команда получает свою ветку, копию репозитория (fork) или доступ на редактирование, и работает с ИИ, чтобы найти и исправить баг.
4. Каждая команда открывает Pull Request в `main`.
5. Вы по очереди мёржите PR, обновляете открытый `index.html` (или деплой) и показываете исправление на экране.

## Исправления

### Проверка номера телефона

Валидация проверяет всю строку вместо удаления нецифровых символов. Допускаются `+7` и следующие 10 цифр либо 11 цифр с начальной `7` или `8`. Номера с буквами, пробелами, скобками, дефисами, точками и переводами строки отклоняются.

### Подсказка к кнопке регистрации

Под неактивной кнопкой отображается список полей, требующих исправления. Подсказка обновляется при вводе и исчезает, когда форма заполнена корректно. Добавлены `role="status"` для объявления изменений и `aria-describedby` для связи подсказки с кнопкой.

### Проверка пароля

Длина пароля ограничена диапазоном от 8 до 30 символов. Обязательны хотя бы одна латинская буква, одна цифра и один спецсимвол. Пробельные символы запрещены.

Сообщение об ошибке указывает конкретную причину: недопустимую длину, пробелы или отсутствие обязательного типа символов.
